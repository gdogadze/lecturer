# Audience floor for week 1

The room is a master's informatics group, COMP M205-1. The week-1 deck assumes some students know Java or Python and a class with a constructor, and does not assume C# syntax or a working SDK. Future sessions should start from that floor: explain `Main` only as the old shape of the same program, and keep the first C# to a primary constructor plus a collection expression.

**Evidence**: The lecturer supplied the syllabus outcomes and the week topics, and the existing deck's speaker notes ask who has written C#, Java, or Python before teaching `Program.cs`.

**Implications**: Do not open week 3 by re-teaching `dotnet new`. Architecture is the next skill. If a lab shows that `dotnet test` never went green, week 3 waits.
