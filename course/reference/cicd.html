GitHub

name: build and test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-dotnet@v6
        with:
          dotnet-version: "10.0.x"
      - run: dotnet format --verify-no-changes
      - run: dotnet test --configuration Release

რიგი: ჯერ კოდი, მერე SDK, მერე შემოწმება. dotnet test წითელდება, თუ ტესტი წითელია. dotnet format --verify-no-changes წითელდება, თუ ფორმატერი ფაილს შეცვლიდა.

ვერსიების წყაროა setup-dotnet, არა GitHub-ის ძველი .NET 6-ის მაგალითი.
