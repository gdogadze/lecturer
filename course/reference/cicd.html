GitHub

name: build and test

on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
      - uses: actions/setup-dotnet@v6
        with:
          dotnet-version: "10.0.x"
      - run: dotnet format --verify-no-changes
      - run: dotnet test --configuration Release

თანმიმდევრობა: ჯერ კოდი, შემდეგ SDK, შემდეგ შემოწმება. dotnet test წითლდება, თუ ტესტი ჩავარდა. dotnet format --verify-no-changes წითლდება, თუ ფორმატერი ფაილს შეცვლიდა.

ვერსიები აიღეთ setup-dotnet-იდან და არა GitHub-ის ძველი .NET 6-ის მაგალითიდან.
